Taito F3 ROM files (.rom) must be placed in this folder (Assets/taitof3/common/).
Build .rom files using tools/build_rom.py from your verified MAME 0.288 romset.
Examples:
  Assets/taitof3/common/dariusg.rom
  Assets/taitof3/common/rayforce.rom
  Assets/taitof3/common/elvactr.rom
  Assets/taitof3/common/bublbob2.rom
