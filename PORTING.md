## 1. Taito F3 System Hardware Overview

The Taito F3 System (1992–1998) was one of the most capable 2D arcade platforms of the 16/32-bit era.

| Component | Hardware | Implementation |
|---|---|---|
| Main CPU | Motorola 68EC020 @ 16 MHz | TG68K.C in 68020 mode (`rtl/tg68k/`) |
| Sound CPU | Motorola 68000 @ 16 MHz | TG68K.C in 68000 mode (`rtl/rf_sound_main.sv`) |
| Sound Synthesizer | Ensoniq ES5505 (OTIS) + MB87078 | Real hardware model (`rtl/rf_es5505.sv`, `rf_mb87078.sv`) |
| Video Processor | Taito TC0630FDP + Zoom/Pivot | Multi-plane tilemaps, 320 KB sprite framebuffer |
| Memory Storage | 93C46 EEPROM (64x16) | Serial EEPROM emulation (`rtl/rf_eeprom_93c46.sv`) |

## 3. Mapping MiSTer Dependencies to Analogue Pocket

| MiSTer Subsystem | MiSTer Implementation | Analogue Pocket Replacement |
|---|---|---|
| Host Communication | `hps_io` (HPS_BUS, ioctl download) | APF Target Bridge + `pk_io.sv` |
| Video Scaling | `sys/ascal.v`, `scandoubler.v`, HDMI | APF native video bridge (RGB 24-bit) |
| Audio Output | I2S via `sys/` HDMI/SPDIF | `sound_i2s.sv` 48 kHz stereo DAC |
| ROM & Tile Storage | SDR SDRAM (32 MB / 64 MB) | Pocket SDR SDRAM (`dram_*`, 64 MB / 512 Mbit) |
| Sprite Framebuffer | DDR3 (`DDRAM_*` Avalon bus, 320 KB) | Pocket Cellular PSRAM 0 (`cram0_*`, 16 MB) |
| Settings / DIPs | OSD `status[]` word | `interact.json` APF variables |
| Input | USB gamepad / PS2 | APF Pad Controller (`pad_key` -> `joystick_0`) |

## 4. Memory Architecture: Two External Memories, Zero Contention

The Cyclone V on the Analogue Pocket (`5CEBA4F23C8`) possesses:
- **64 MB (512 Mbit) 16-bit SDR SDRAM (`dram_*`):**
  - Exactly matches the SDR protocol of `rf_sdram.sv`.
  - Holds the entire concatenated game ROM stream (up to Profile 1's 42 MB with 22 MB headroom).
  - Supplies 8 arbiter channels:
    - `ch1`: Playfield tile plane 1
    - `ch2`: Playfield tile plane 2
    - `ch3`: CPU program bus (`rf_prog_bus`) & download loader
    - `ch4`: Sprite bus A graphics
    - `ch5`: Sound 68000 program bus
    - `ch6`: ES5505 Ensoniq sample bus
    - `ch7`: Sprite bus B graphics
    - `ch8`: Pivot RAM in SDRAM
- **16 MB Cellular PSRAM 0 (`cram0_*`):**
  - Completely dedicated to the 320 KB sprite framebuffer (`rf_spr_fb.sv`).
  - Completely frees SDRAM from framebuffer contention.
  - No DDR3 controller needed.

## 5. Clock Synthesis (Pocket 74.25 MHz Reference)

Using integer counters in the Cyclone V PLL (`f3_pll.sv`):
- `f_vco = 74.25 MHz * 115 / 8 = 1067.34375 MHz` (within 600..1300 MHz VCO limits)
- `clk_ram = 1067.34375 / 11 = 97.03125 MHz` (SDRAM controller, 0.009% error from 97.04 MHz)
- `clk_sys = 1067.34375 / 20 = 53.367187 MHz` (F3 system, 0.009% error from 53.372 MHz)
- `clk_pix = 1067.34375 / 160 = 6.670898 MHz` (APF pixel clock, 8x division of clk_sys)
- `clk_pix_90`: +90 degree phase shift for APF DDR video sampling.

## 6. ROM Format (.rom) for Analogue Pocket

The ROM images generated by `tools/build_rom.py` have a 16-byte header:
- `[0..3]`: Magic `TF3\x01`
- `[4..5]`: `game_cfg` (16-bit LE): visarea, extend mode, map profile, palette 12-bit, game ID
- `[6..7]`: Reserved (`0x0000`)
- `[8..11]`: `rom_len` (uint32 LE)
- `[12..15]`: CRC32 checksum (uint32 LE)
- `[16..]`: Interleaved ROM payload

When loaded via openFPGA, `pk_io.sv` automatically extracts the header and configures the core without requiring manual DIP switch adjustments.
